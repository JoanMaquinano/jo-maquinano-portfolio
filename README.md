# Joan Maquinano — Portfolio

A static portfolio showcasing data analysis, data engineering, ESG, and research work.

## Run locally

Open `index.html` in a browser, or start a local server from the repository root:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — portfolio, featured work, case studies, experience, skills, and education
- `*-case.html` — detailed project case studies
- `assets/` — images, icons, and shared editorial styles
- `scripts/` and `.github/workflows/` — profile synchronization tooling

The site uses plain HTML, CSS, and JavaScript with Bootstrap loaded from a CDN.
