Instacart Dimensional Warehouse

An end-to-end data engineering project that transforms raw Instacart transaction data into validated, analytics-ready fact and dimension tables.

Databricks SQL Delta Lake Dimensional Modeling

The Goal

Build a dependable warehouse layer that makes grocery-order data easier to query, validate, and use for reporting and business analysis.

My Collaboration Context

Developed collaboratively on GitHub, with shared documentation, version control, reviewable SQL transformations, and reproducible pipeline steps.

How the Pipeline Works

The workflow follows a medallion architecture: raw source files are ingested into Bronze, cleaned and standardized in Silver, then modeled into a Gold layer for analytics.

Bronze

Preserves source data and establishes traceable ingestion.

Silver

Applies cleaning, standardization, integration, and quality checks.

Gold

Publishes fact and dimension tables for reporting and analysis.

Example Output

The project also supports analysis of order timing, weekday and weekend patterns, average basket size, and reorder behavior.
