NYC Mobility Data Pipeline

Integrating trips, weather, geography, and traffic context into a trusted, analytics-ready mobility dataset.

This Databricks project brings together NYC Green Taxi trips, historical weather, taxi zone reference data, and traffic advisories. Its Medallion pipeline is designed for repeatable incremental processing, explicit quality validation, and dependable downstream analysis.

02 · Architecture

Medallion layers with checks between transformations.

Bronze · land

Load source records with audit context and minimal transformations, keeping the original inputs available as a traceable starting point.

Silver · standardize

Clean fields, standardize formats, deduplicate records, and apply quality rules before data moves into curated models.

Gold · serve

Publish fact and dimension tables that align trips with date, taxi-zone, and weather context for trusted analytics.

Repeatable runs. Incremental loading and idempotent write patterns are designed to make reruns safe and avoid duplicate output when processing the same inputs again.
03 · Analytical use

A foundation for asking better mobility questions.

Questions the integrated data can support

  • When and where is taxi demand highest?
  • How do trip patterns vary with weather conditions?
  • Which pickup and drop-off zones show the most activity?
  • How can traffic advisories add context to observed mobility patterns?

Engineering practices in focus

  • Databricks Asset Bundles for repeatable project deployment.
  • Incremental source loading and idempotent processing.
  • Deduplication and validation at the appropriate data layers.
  • Repository-based CI/CD and collaborative review workflows.

Project details are summarized from the NYC Mobility repository and its project description. The repository documents the initial pipeline scope; no production deployment or quantified business impact is claimed here.
